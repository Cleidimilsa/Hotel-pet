HOTEL PET – ETAPAS 2 E 3 (PROGRAMAÇÃO WEB II)

CONTEÚDO
- Etapa 2 – Buscas: pesquisa dinâmica em Reservas, Pets e Usuários.
- Etapa 3 – Edição de tabelas: edição de reservas, pets e funções dos usuários.
- Configurações: edição do valor da diária e do total de vagas.
- Dashboard: resumo atualizado com base nos dados salvos.

COMO EXECUTAR
1. Extraia a pasta Hotel-Pet-Etapas-2-e-3.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador (ou use a extensão Live Server, se já estiver instalada).
4. Navegue pelo menu lateral para testar as páginas.

COMO TESTAR A ETAPA 2
- Reservas: pesquise por ID, nome do pet, proprietário ou status.
- Pets: pesquise por nome, tipo, raça, tamanho ou proprietário.
- Usuários: pesquise por nome, e-mail ou função.
- Digite parte de uma palavra; os resultados são filtrados enquanto você digita. Use Limpar para restaurar a lista.

COMO TESTAR A ETAPA 3
- Em Reservas, clique em Editar, altere os campos e clique em Salvar alterações. Uma reserva Finalizada também pode ser editada pelo gerente.
- Em Pets, clique em Editar, altere os dados e salve.
- Em Usuários, escolha outra função e clique em Salvar.
- Em Configurações, altere o valor da diária ou o número de vagas e salve.

TECNOLOGIAS E LIMITAÇÕES
HTML5, CSS3 e JavaScript puro. Não são utilizadas bibliotecas ou frameworks e não há backend. Os registros iniciais são fictícios/demonstrativos. As alterações ficam no localStorage do navegador utilizado; portanto, não são compartilhadas entre computadores ou navegadores. Para restaurar os dados iniciais, limpe os dados/localStorage do site no navegador.
