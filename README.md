# Hotel Pet — Projeto Final (HTML + CSS)

Projeto acadêmico de site estático para gerenciamento de hospedagem de pets.

## Escopo
- Visão desenvolvida: **Gerente**, conforme enunciado.
- Tecnologias: **HTML5 + CSS3**.
- Sem bibliotecas ou frameworks.
- Sem backend e sem banco de dados.
- Conteúdo demonstrativo e estático.
- Imagens locais em SVG para personalização visual.

## Páginas
- `index.html` — Dashboard
- `reservas.html` — consulta, cadastro e edição de reservas
- `pets.html` — cadastro, pesquisa e ficha de pets
- `usuarios.html` — gerenciamento de clientes, funcionários e gerentes
- `configuracoes.html` — valor das diárias e número de vagas
- `perfil.html` — perfil do gerente
- `css/style.css` — folha de estilos
- `img/` — imagens locais

## Requisitos contemplados
1. HTML estruturado e semântico.
2. CSS personalizado com cores, tipografia, cards, tabelas, formulários e responsividade.
3. Navegação entre páginas.
4. Visão do gerente.
5. Reservas, pets, usuários e configurações.
6. Campos previstos no enunciado para gerente: alteração de reserva finalizada, função do usuário, valor da diária e quantidade de vagas.
7. Interface estática, sem backend.

## Entrega no GitHub
1. Crie um repositório chamado `hotel-pet`.
2. Envie todos os arquivos mantendo as pastas `css` e `img`.
3. Faça commits separados para evidenciar as etapas:
   - `Semana 1 - Estrutura HTML do Hotel Pet`
   - `Semana 2 - Personalização CSS do Hotel Pet`
4. Ative o GitHub Pages para publicar o `index.html`.

## Observação
Os botões e formulários representam as ações do sistema. Como o trabalho não possui backend, eles não persistem dados.
